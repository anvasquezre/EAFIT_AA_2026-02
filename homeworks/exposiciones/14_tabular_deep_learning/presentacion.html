Machine learning vs. deep learning

Machine learning

Una persona diseña las características. El modelo aprende las reglas. Ejemplos: árboles, regresión.

Deep learning

La red aprende sola las características a partir de los datos. Es un tipo de machine learning con redes de muchas capas.

La diferencia: quién decide qué mirar

Machine learning

Una persona le enseña qué mirar: orejas, bigotes, nariz.

Deep learning

La red descubre sola qué mirar: bordes, formas y patrones.

Machine learning: le enseñas qué aprender. Deep learning: lo aprende solo.

Deep learning vs. árboles

Deep learning

  • Red neuronal de muchas capas que descubre por sí misma qué características importan
  • Muy potente con imágenes, audio y texto
  • Requiere grandes cantidades de datos y mucho cómputo

Árboles (GBDT)

  • XGBoost, LightGBM y CatBoost
  • Muy competitivos o superiores en datos tabulares
  • Baseline imprescindible: costo, velocidad y robustez

La neurona: la pieza básica

  • Cada entrada se multiplica por su peso
  • Se suman los resultados y se añade el sesgo (bias)
  • Una función f(x) produce la salida

Muchas neuronas conectadas forman una red neuronal profunda.

Output = b + Σi=1n xi wi

Deep learning: MLP

  • MLP: Multi Layer Perceptron
  • Capas: Input, Hidden y Output
  • Cada neurona se conecta con todas las de la capa anterior y la siguiente
  • Cada capa aporta a la predicción
  • Nº de capas y neuronas = hiperparámetros

El reto: las tablas no tienen estructura

En una imagen

Los píxeles vecinos se relacionan. La red aprovecha esa cercanía.

En una tabla

Cambiar el orden de las columnas no cambia su significado. No hay vecindad que explotar.

Cuatro obstáculos para las redes

Datos heterogéneos

Números, categorías y fechas conviven en la misma fila.

Pocos datos

Muchas tablas tienen miles de filas, no millones.

Columnas irrelevantes

Solo algunas columnas importan. La red puede distraerse.

Valores extremos

Un ingreso muy alto desestabiliza el aprendizaje.

Cómo se resuelve

1 · Preparar

Escalar los números, reducir valores extremos y tratar los datos faltantes.

2 · Representar

Convertir cada categoría en un vector que la red aprende: un embedding.

3 · Entrenar con cuidado

Regularización y datos de validación para evitar que memorice.

Ventajas y desventajas

Ventajas

  • Aprenden las características sin diseñarlas a mano
  • Embeddings reutilizables
  • Preentrenamiento y transferencia entre tablas
  • Combinan tablas, texto e imágenes

Desventajas

  • Necesitan más datos
  • Entrenar cuesta más tiempo y cómputo
  • Son más difíciles de ajustar
  • Son menos interpretables

Consejo práctico

  1. Empieza con LightGBM, XGBoost o CatBoost
  2. TabPFN si tienes pocas filas
  3. TabM o MLP-PLR si hay muchos datos o multimodalidad
  4. Combina en un ensemble

El deep learning en tablas no es mejor por defecto: ofrece flexibilidad que los árboles no tienen.
